# 账号登录

## 开发自动登录

本机开发可在启动 API 前设置 `APP_ENV=development`、`DEV_AUTO_LOGIN=1`。
Vite 开发页面仅在浏览器没有登录历史标记时尝试自动登录已有的 `admin` 账号。
可通过 `DEV_LOGIN_USER` 指定其他已有账号。手动退出或会话过期后刷新不会再次自动登录，需要手动登录。
关闭 `DEV_AUTO_LOGIN` 或不设置 `APP_ENV=development` 即恢复正常登录。
开发登录接口仅接受本机地址访问；生产构建不会自动调用该接口。

1. 在浏览器打开 `http://localhost:5173`。
2. 首次使用会显示“创建管理员”，自行设置用户名、姓名和至少 8 位密码。
3. 管理员登录后，从右上角汉堡菜单进入“用户管理”添加普通用户或其他管理员。
4. 后续用户使用分配的账号登录；右上角菜单可切换语言、币种或退出登录。

所有登录用户可以使用现有报销、审批功能；只有管理员可以查看和添加账号。
当前不按用户隔离报销数据，也未增加审批专属角色。
新审批记录的操作人由服务器取自登录账号，历史手填记录保持原样。

密码使用带随机盐的 PBKDF2-SHA256 存储，登录会话通过 HttpOnly Cookie 保存，8 小时后过期，退出后立即失效。
连续 5 次错误密码会将该用户名的登录暂停 5 分钟。
本地开发请统一使用 `localhost` 地址。部署 HTTPS 时设置 `COOKIE_SECURE=1`，并在后端配置实际前端来源。

验证：设置项目数据库环境变量后运行 `python -m backend.test_auth` 和 `python -m backend.test_batches`。
测试使用独立 schema 并回滚，不会留下测试账号。
